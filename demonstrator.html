Shared information that applies to all versions. Scenarios live on their version pages (V1–V4). Build new scenarios on the Create page and tag them to a version. You are admin — common info below is editable and saves to the database.

The safety principle behind every decision: SENA is an extra vigilant eye that errs toward alerting. Every real event reaches the parent — never silently ignored. When unsure, it alerts anyway. A false alarm is a minor annoyance; a missed child is not acceptable.

Night escalation

How it works now: a child-boundary event at night (e.g. 10 PM–6 AM) raises posture — notify immediately, shorter waits, all owners at once. Night changes how urgently we treat the event, never what happened.
Board input: set what counts as "night," which zones count, and how much to escalate. Discuss in scenario comments on the version pages.
